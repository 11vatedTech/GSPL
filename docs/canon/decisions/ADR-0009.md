# ADR-ADR-0009: Relationship between compiler knowledge and seed payload

**Status:** Accepted (Prompt 1 baseline)
**Date:** 2026-07-14
**Decision-maker:** GSPL Canon foundation

## Context

Seed may reference compiler knowledge (knowledge-base version) or embed it.

## Competing Options

(1) Embed all. (2) Reference by content hash. (3) Hybrid.

## Evidence

Spec/05 uses content-hash. Seed metadata pins knowledge version.

## Decision

Option (2). Seed references external content-addressed knowledge.

## Consequences

Seed remains small. Reproducibility becomes a federation problem.

## Risks

If knowledge is missing or modified, determinism breaks.

## Unresolved Questions

Minimum knowledge-base scope.
