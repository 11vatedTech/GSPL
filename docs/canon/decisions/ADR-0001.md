# ADR-ADR-0001: What GSPL fundamentally represents

**Status:** Accepted (Prompt 1 baseline)
**Date:** 2026-07-14
**Decision-maker:** GSPL Canon foundation

## Context

The canonical repository must declare what GSPL is, beyond the prototype implementations surfaced by earlier work.

## Competing Options

(1) GSPL is a programming language. (2) GSPL is a generative programming substrate. (3) GSPL is a translation bridge.

## Evidence

Spec/00 frames the seed as primary. Reference repositories align with reading (2).

## Decision

GSPL is a generative programming substrate (reading 2) with optional surface-level GSPL source authoring.

## Consequences

The translation bridge is load-bearing. The kernel/gene-system are at the substrate level.

## Risks

Misreading GSPL as just a language produces misunderstanding of the translation bridge.

## Unresolved Questions

Whether the GSPL source language ever becomes the dominant authoring surface for canon-internal use.
