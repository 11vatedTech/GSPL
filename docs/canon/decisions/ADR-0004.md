# ADR-ADR-0004: Gene model disposition

**Status:** Accepted (Prompt 1 baseline)
**Date:** 2026-07-14
**Decision-maker:** GSPL Canon foundation

## Context

The reference spec/02 lists 17 gene types. Closed inventory vs. open type system.

## Competing Options

(1) Closed 17. (2) Closed 17 with extension protocol. (3) Fully open.

## Evidence

Spec/02 claims irreducibility. EXTENSIBILITY PROTOCOL is documented.

## Decision

INITIAL 17 inventory with bounded extensibility.

## Consequences

Adding a gene type is a major canon event. The empire effects are bounded.

## Risks

Misreading 17-as-closed contradicts the canon.

## Unresolved Questions

Empirical irreducibility proof.
