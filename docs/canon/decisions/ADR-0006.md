# ADR-ADR-0006: Determinism model

**Status:** Accepted (Prompt 1 baseline)
**Date:** 2026-07-14
**Decision-maker:** GSPL Canon foundation

## Context

Reproducibility-by-construction is the load-bearing claim.

## Competing Options

(1) Best-effort. (2) RFC-grade cryptographic primitives. (3) Best-effort + signed gateway.

## Evidence

Spec/03 mandates PRNGs; spec/05 mandates SHA-256 + JCS. Implementation exists.

## Decision

Option (2): SHA-256, JCS RFC 8785, ECDSA P-256 RFC 6979 are LOCKED primitives.

## Consequences

SC-002 cross-architecture parity is the decisive criterion. RNG modules ship test vectors.

## Risks

Compiler-induced float drift breaks parity.

## Unresolved Questions

Cross-architecture parity and typed tolerance.
