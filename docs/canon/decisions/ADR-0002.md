# ADR-ADR-0002: Whether source code is canonical

**Status:** Accepted (Prompt 1 baseline)
**Date:** 2026-07-14
**Decision-maker:** GSPL Canon foundation

## Context

If source code is canonical, the seed is a derived view; if not, the seed is canonical and source is one projection.

## Competing Options

(1) Source code is canonical. (2) Seed is canonical inside GSPL. (3) Both.

## Evidence

Spec/01 places fields on the seed. MVP_DEFINITION Tier E roundtrips seed-only playable games.

## Decision

Source code IS canonical externally; inside GSPL canonical tools, the seed IS canonical.

## Consequences

Round-trip is an enforced property, translation bridges conform to graduated fidelity.

## Risks

If the external reading is misused inside the canon, source-as-projection semantics breaks.

## Unresolved Questions

Round-trip validation surface size and tolerance bands.
