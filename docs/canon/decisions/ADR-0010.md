# ADR-ADR-0010: Relationship between GSPL and domain products

**Status:** Accepted (Prompt 1 baseline)
**Date:** 2026-07-14
**Decision-maker:** GSPL Canon foundation

## Context

Marketplace, studio, federated services are not the language.

## Competing Options

(1) Everything in monorepo. (2) Exclude. (3) Subset with boundaries.

## Evidence

GSPL_SCOPE_AND_NON_GOALS.md explicitly excludes studio/market/federation.

## Decision

Option (3). Canon is the seam between core components and downstream products.

## Consequences

Downstream products consume artifacts instead of importing canonical code.

## Risks

Implementing downstream products canon-side causes scope creep.

## Unresolved Questions

Distribution path for canon-foundation tools.
