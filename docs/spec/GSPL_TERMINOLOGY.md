# GSPL Terminology

**Version:** 1.0

## Canonical Terms

| Term | Definition |
|------|------------|
| Canonical Seed | Normalized, content-addressable representation of a GSPL program |
| Gene | A typed value in the seed payload governed by the gene protocol |
| GSPL IR | Intermediate Representation: typed attributed graph |
| Expansion Plan | Ordered, executable plan with operations and parallel groups |
| Artifact Graph | Target-neutral artifact representation with content and provenance |
| JCS | JSON Canonicalization Scheme (RFC 8785) |
| SplitMix64 | Deterministic PRNG used for entropy channels |
| Hash Policy | Field-level declaration of HASHED/NON_HASHED/DERIVED status |
