# GSPL Canon Foundation

Generative Seed Programming Language (GSPL) is the canonical reference for an original programming paradigm by 11vatedTech LLC, founder Kahlil Stephens.

This repository consolidates the founding documents, audit, provenance ledger, claim classifier, reference indexer, and the canon-foundation package implementing SHA-256, JCS canonicalization, deterministic RNG, the 8-phase tick cycle, the 8 invariant validators, and the 7-axis discipline.

## Structure
